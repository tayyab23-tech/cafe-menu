CHAI CORNER WEBSITE

Files:
- index.html   : Home page
- menu.html    : Menu page
- order.html   : Order Online page
- about.html   : About Us page
- contact.html : Contact Us page
- style.css    : Shared styling for all pages
- script.js    : JavaScript for the demo forms
- images/tea-cup.svg : Local tea-cup illustration

HOW TO RUN:
1. Extract the ZIP file.
2. Open the chai_corner_website folder in VS Code.
3. Open index.html in a browser, or use Live Server.
4. Use the navigation bar to visit the other pages.

IMPORTANT:
- The original menu items and prices are preserved:
  Tea - Rs. 80
  Coffee - Rs. 150
  Paratha - Rs. 100
- The website uses only HTML, CSS and JavaScript.
- Order and contact forms are front-end demonstrations only.
  They do not send data to a real business or server.
- No real cafe address, phone number or email has been invented.
